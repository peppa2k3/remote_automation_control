# Sửa code ở đâu?

| Phần | Đường dẫn |
|---|---|
| Trang/giao diện | `frontend/src/app/`, `frontend/src/features/` |
| Đăng nhập/session | `backend/src/modules/auth/` |
| Pair/heartbeat/quyền máy | `backend/src/modules/devices/` |
| Database/migration | `backend/prisma/` |
| CLI/kết nối/DPAPI Agent | `agent-windows/src/core/` |
| Payload chung | `packages/contracts/` |
| Hạ tầng local/VPS | `infrastructure/compose/`, `infrastructure/vps/` |
| Cấu hình và kiểm tra | `scripts/` |
| Prompt và nhật ký | `docs/promt/`, `docs/processing/`, `docs/completed/`, `docs/IMPLEMENTATION_LOG.md` |

Luồng và quy tắc module: [ARCHITECTURE](../ARCHITECTURE.md). Bắt đầu chạy tại [start-here](start-here.md).
